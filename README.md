# git tutorial
### initialize git (not needed if cloned from git)
``git init``

### connect the local folder to github
``git remote add origin https://github.com/hcg-leo/<repo_name>``

### set which branch
``git branch -M main``

### prepare files to be saved (dot means everything in directory, replace it with directory for  specific)
``git add .``

### commit your files
``git commit -m "<your_message>"``

### push your files
``git push -u origin main``
